# 기획 초안: AI LIMIT 모티브 소울라이크 (2026-10-13)

> **상태:** 초안. 이름과 용어는 모두 가칭이다. 사용자 검수 후 확정한다.
>
> **방향:** 스팀 게임 *AI LIMIT*(無限機兵, SenseGames, 2025)의 골자(세계 구조, 핵심 시스템, 이야기 흐름)를 따라가되, 모든 메인 NPC를 서브컬처풍 여성 캐릭터로 바꾼다. Minecraft 1.21.1 + NeoForge로 만든다.
>
> **원작 자료:** [`sources/notes_ailimit.md`](sources/notes_ailimit.md) (영어, 출처 URL 포함, 스포일러 있음)

## 1. 원작에서 가져오는 것과 가져오지 않는 것

| 가져온다 (구조와 시스템) | 가져오지 않는다 (표현) |
| --- | --- |
| 스태미나 없이 싱크율 하나로 돌아가는 전투 | 원작의 이름 (인물, 지역, 신, 용어) |
| 체크포인트에서 회복·적 재생성·레벨업·강화·빠른 이동 | 캐릭터 디자인 (예: 주인공의 짧은 흰머리, 붉은 눈, 왼팔 의수 조합) |
| 사망 시 재화 일부 손실, 회수 없음 | 대사, 텍스트, 이미지, 음악, 모델 |
| 왼팔 방어 기능 4종, 주문, 무기 6계열, 무기 2개 교체 | |
| 오염된 폐허 도시, 세 AI 신의 실험이라는 세계관 뼈대 | |
| 지역 순서, 숏컷으로 이어지는 층층 구조, NPC 퀘스트에 따른 엔딩 분기 | |

일반적으로 게임 규칙과 구조 같은 아이디어는 보호 대상이 아니지만, 이름, 캐릭터 디자인, 글, 그림, 음악 같은 표현은 보호된다. 그래서 표현은 모두 새로 만들고, 작품 소개와 크레딧에는 "AI LIMIT에서 영감을 받음"이라고 밝힌다.

## 3. 핵심 시스템과 구현 방법

| 원작 시스템 | 우리 작품 | 구현 | 난이도 |
| --- | --- | --- | --- |
| **스태미나 없음 + 싱크율** (0~100%, 0~IV단계, 공격력 90~130%, 0단계면 스킬·주문 봉인, 0% 아래로 떨어지면 경직 후 50% 복구) | 공명율 | **커스텀 모드**. Epic Fight 스태미나를 사실상 끄고(최대치·회복 속성), 공명율을 플레이어 데이터로 따로 관리한다. 맞히면 오르고 맞으면 내려간다. HUD는 모드가 그린다 | **높음 (핵심 기술 과제)** |
| 적 검희의 싱크 게이지, 바닥나면 처형 | 라이벌 보스 공명율 | 같은 시스템을 보스에 붙이고, 0이 되면 Epic Fight 처형 연출 | 높음 |
| Branch 60개 (회복, 적 재생성, 레벨업, 강화, 빠른 이동, 육성, 인장 교체) | 묘목 | 커스텀 블록과 화면. 쉴 때 구역 스포너를 초기화한다 | 중간 |
| 사망 시 정수 일부 손실 (장착한 핵의 유지율), 회수 없음 | 정수 | 커스텀 모드 데이터 | 낮음 |
| Life Dew (3→10회 충전, 회복량 강화) | 수액 병 | 커스텀 아이템, 묘목에서 충전 | 낮음 |
| 왼팔 기능 4종: 패리(즉발), 방패, 클로(체력→공명율), 대시(완벽 회피) | 왼팔 기능 | Epic Fight의 가드·패리·스텝 스킬을 바탕으로 커스텀 스킬 | 중간 |
| 주문 (레일건, 미사일, 번개, 광선, 무기 강화, 회복), 공명율 소모 | 술식 | 커스텀 스킬. 공명율을 쓴다 | 중간 |
| 무기 6계열: 장검, 태도, 쌍검, 대검·낫, 창, 클로. 2개 장착, 콤보 중 교체 공격 | 무기 | Epic Fight 무기 타입 데이터팩 + 모션. 교체 공격은 커스텀 | 중간 |
| 인장 (주 인장 = 직업, 일반 인장 = 게이지 구간과 효과) | 문장 | 장신구 슬롯(Curios 1.21.1판 확인 필요) + 모드 | 중간 |
| 5스탯 (생명, 활력, 근력, 기교, 정신), 레벨업 | 5스탯 | 모드 속성 | 낮음 |
| 무기 +1~+10 강화, 재료 4종 | 강화 | 모드와 데이터팩 | 낮음 |
| 엔딩 3개, NPC 퀘스트 완료 여부로 분기 | 엔딩 | 데이터팩 진행 플래그 | 중간 |

**가장 큰 위험은 공명율이다.** Epic Fight는 스태미나 중심으로 설계돼 있다. 1단계(모드 골격)에서 Epic Fight 21.17.3.1 소스(1.21.1판은 GPLv3)를 읽고, 공격 적중·피격·스킬 사용 이벤트에 공명율을 연결할 수 있는지 먼저 시험 구현으로 확인한다.

## 5. 범위 (2026-10-13 결정)

**원작의 골자 전체를 만든다.** 지역 14개, 엔딩 3개까지 간다. 과제는 그중 첫 마일스톤까지만 제출한다.

| 마일스톤 | 내용 | 비고 |
| --- | --- | --- |
| **M1. 과제 제출본** | 원작 1~2구역에 해당하는 **하수도 마을 남서부 → 외벽 폐허 빈민가(캠프)**. 이 구간 보스 4개(원작의 하수도 청소부, 창기사, 약탈자 족장, 공포의 수확자에 해당하는 새 보스). 이 구간에서 만나는 NPC. **핵심 시스템 전부**(공명율, 묘목, 정수, 수액 병, 왼팔 기능, 술식, 무기 계열 일부) | 시스템을 끝까지 완성해서 보여 준다 |
| M2 이후 | 침수 도시부터 원작 순서대로 지역을 늘린다. 엔딩 3개까지 | 과제 이후 계속 |

M1 구간에 어떤 NPC가 나오는지, 보스 패턴이 정확히 어떤지는 2차 조사(원작 지역·전투·서사) 결과로 확정한다.

## 6. 다음 단계

1. 2차 대규모 조사(원작, 모델링, 맵 분위기, 세부 건축) 결과 반영. 사용자 결정: 용어·이름 가칭 승인
2. 1단계 개발 시작: NeoForge 1.21.1 모드 골격 + **공명율 시험 구현**(Epic Fight 연동 확인)
3. 첫 레퍼런스 시트: 주인공 리네아 (실루엣, 팔레트, 핵심 디테일) → 사용자 승인 → 모델링
4. 첫 보스 무브 시트: 원작 첫 보스(하수도 청소부)에 해당하는 보스
