## 1. M1 구간 레벨 구조

### 1.1 하수도 마을 남서부 (원작 체크포인트 4개)
- **플레이 시간** [확인]: 처음 하는 사람 42~72분, 수집하며 빠르게 12~26분. 무료 체험판 구간이었다.
- **흐름** [확인]
  1. 진흙 속에서 깨어남 → 쇠창살 너머 선택 맹수 → 배수관 안 뒤잡기 튜토리얼 → 로봇 문지기 중간 보스
  2. 발목까지 검은 물이 찬 원형 탱크실, **첫 체크포인트와 안내자**
  3. 승강기를 타고 올라가면 **대표 장면**: 반대편이 안 보이는 안개 낀 저수조. 저 끝에서 거대 레이저 기계가 쏜다. 모래주머니 엄폐물 사이로 건넌다
  4. 두 번째 체크포인트 주변이 유일한 미로 구간
     - 좁은 다리 위의 중장 적, 위에서 던지는 적
     - 상자 밑에 숨은 바닥 해치, 갈라졌다 다시 만나는 길
     - **초록 불 문 = 체크포인트로 돌아오는 지름길, 빨간 불 문 = 열쇠 필요**
     - 완전히 어두운 매복 방
  5. 복도에서 기계의 고정 손을 쳐서 쓰러뜨리면 협곡으로 떨어지고, 좁은 빔 위에 저수조 열쇠가 남는다
  6. 열쇠 쪽 선택 우회로: 달팽이 → 중간 보스 → 아주 긴 사다리로 고리가 닫힌다
  7. 본길: 길 잃은 블레이더가 괴물을 죽이는 장면을 보여 준 뒤 플레이어에게 덤빈다. 미끼 적 옆 바닥에서 적이 솟아오른다. 녹슨 거대 로봇 껍데기가 쌓인 마당
  8. 그 마당에서 왼쪽 승강기로 올라가면, 처음에 부서진 다리 너머로 보였던 아이템과 자판기가 있다. **시작 지점으로 돌아오는 고리**
  9. **한 번 떨어지면 못 돌아오는 낙하**로 안개와 불티가 날리는 침수된 홀(보스방)에 들어간다 → 보스 뒤 체크포인트와 기억 장면 → 출구 승강기
- **이야기 장치** [확인]: 지상으로 달아나는 사람을 비웃는 하수도 주민, 문의 "진흙 채취장 5호" 표지, 열쇠 아이템을 주우면 짧은 음성 조각이 나온다.
- **색** [커뮤니티]: 청회색과 청록, 검은 물, 호박색 기계 조명.

### 1.2 구간 전환 [확인]
승강기 → 맨홀 → 계단 → **성벽 도시가 한눈에 보이는 타이틀 경치** → 시체에서 지도 획득(지역 연결만 표시) → 바로 아래 체크포인트.

### 1.3 외벽 폐허 빈민가 (원작 체크포인트 5개)
- **플레이 시간** [확인]: 처음 40~75분, 빠르게 12~26분.
- **흐름** [확인]
  1. 위에서 화염병을 던지는 적, 실내 폭발 드럼이 있는 내리막 거리
  2. **안전한 캠프 거점**: 가운데 모닥불, 이야기 NPC, 허수아비. 부식체가 들어오지 못하는 결계
  3. 순례자 증표를 요구하는 문지기
  4. **저격수 구간**: 빨간 레이저 조준선이 주황으로 바뀐 뒤 발사. 엄폐하며 올라가서 처치하면 다시 생기지 않는다
  5. 지름길: 캠프로 돌아오는 양문, 걷어차 내리는 사다리
  6. 지붕 전투: 화염방사 로봇, 양쪽 지붕의 척탄병
  7. 사다리 위 높은 단의 세 번째 체크포인트
  8. 선택 승강기 고리: 아래 협곡의 약탈자 발굴장(부식체가 약탈자를 습격해 서로 싸움) → 회복 강화를 떨어뜨리는 나비가 있는 **푸른 수정 동굴** → 빈민가로 다시 올라오는 짧은 하수도
  9. 경사로에서 굴러오는 통 → 보스가 아레나로 뛰어든다(약탈자 족장) → 싸운 뒤 문이 열림
  10. 부식체가 장악해 가는 오르막: 큰 고목 앞 연출 전투, 사다리 지름길, 가시 알 함정
  11. 캠프에서 산 열쇠로 여는 선택 묘지 결투
  12. 보스 광장 앞 엄폐된 체크포인트 → 공포의 수확자 → 수도원 체크포인트 → 승강기 → 교단 포털
- **시선 유도** [커뮤니티]: 시작 지점의 높은 곳에 원거리 적을 두어 플레이어를 위로 이끈다. 거대한 외벽, 갈비뼈 같은 금속 아치, 저격탑, 고목이 랜드마크다.
- **색** [커뮤니티]: 따뜻한 세피아, 모래 안개, 골함석. 대비로 차가운 푸른 수정 동굴.

### 1.4 원작 전반의 레벨 패턴
- **체크포인트 간격** [확인]: 거의 모든 보스 바로 앞과 뒤에 하나씩, 그 사이에 지름길이 열린 뒤 1~2개.
- **지름길 도구** [확인]: 한쪽에서만 열리는 문, 초록·빨간 불 문, 걷어차는 사다리, 승강기(다른 층에 있는 승강기는 추락 함정), 상자로 가린 해치. 체크포인트 구간마다 보통 하나의 지름길이 체크포인트로 돌아온다.
- **지역 연결** [확인]: 승강기, 교단 포털, 열차, 균열, 뛰어내리는 구멍.
- **연출** [확인]: 세력끼리 싸우는 장면, 저격 구간, 거대 기계, 다시 생기지 않는 보물 지킴이, 나비가 있는 수정 동굴.
- **칭찬** [커뮤니티]: 서로 이어지는 고리, 높낮이, 비밀.
- **비판** [커뮤니티]: 로딩 화면으로 끊기는 전환, 뻔한 경로, 모퉁이마다 매복, 휑한 회색·갈색 공간, 어색한 점프와 낙하 퍼즐.
- **개발자** [확인]: 제작자는 "자유로운 탐색, 복잡하지 않은 동선, NPC를 통한 정보 공개 순서"를 함께 맞추기가 가장 어려웠다고 했다. 큰 장면은 콘셉트를 먼저 만들고 1~2일짜리 저비용 프리뷰로 검증했다.

### 1.5 우리 작품에서
| 살릴 것 (구조와 감각) | 바꿀 것 |
| --- | --- |
| 좁은 통로 → 안개 낀 거대 저수조와 적대 거대 기계 | 로딩 없는 이음새 없는 전환 |
| 두 번째 체크포인트 주변의 지름길 문·열쇠 문·시작점으로 돌아오는 승강기 고리 | 방 묶음마다 예고된 매복은 최대 하나 |
| 돌아올 수 없는 낙하로 보스방 진입, 뒤에 체크포인트와 기억 장면 | 본길의 점프는 관대하게 |
| 승강기 → 맨홀 → 경치 → 지도 → 체크포인트로 이어지는 출구 연출 | 휑한 공간은 장식하고 지역마다 색을 분명히(청록 하수도 / 세피아 빈민가) |
| 빈민가의 모닥불 캠프, 증표 문지기, 조준선 저격수, 지붕 전투, 푸른 수정 동굴 고리, 괴물이 이기고 있는 오르막 | 원작 이름·디자인·대사는 쓰지 않음 |
| 열쇠 아이템을 주울 때 짧은 대사, 미리 보여 주는 잠긴 문 | |

## 2. 전투 수치

팬이 게임 파일에서 추출해 공개한 테이블(Steam 빌드 23010530, Unity 2022.3)을 찾았다. 보스 체력, 공격력, 강인도, 패리 경직, 회전 속도, 인장별 게이지 구간, 무기·스킬 수치가 들어 있다. 원본 데이터는 저장소에 넣지 않았고, 출처와 쓰는 수치만 노트에 남겼다.

### 2.1 플레이어 [확인, 패리 판정창 제외]
| 항목 | 값 |
| --- | --- |
| 체력 | 생명 10에서 500, 15에서 585, 20에서 685 |
| 공명율 증가 | 적중당 소형 무기 3%, 대형 무기 4% (변환 능력치/100 배율). 창은 약공 연속으로 4→5→6. 교체 공격·차지 공격이 더 높다(장검: 약공 3, 교체 5, 차지 6). 처형 일격 +20%, 처치 +1/2/3% |
| 자연 회복 | 0단계까지만, 소모 2초 뒤 시작 |
| 붕괴 | 0% 아래로 떨어지면 경직, 이후 50%로 복구 |
| 단계별 배율 | 공격 90/100/110/120/130%, 스킬은 IV단계에서 155%, 주문은 0단계에서 사용 불가·IV단계에서 +72%, 처형 ×0.9~1.3 |
| 처형 일격 | 무기와 무관. 캐릭터 레벨 1/10/20에서 기본 350/400/470 × (1 + 0.4·근력 + 기교 보정). '파쇄' 속성 피해이고, 보스는 보통 파쇄 방어가 가장 약하다 |
| 수액 병(원작 Life Dew) | 기본 270 회복, 강화 1/2개면 390/500(최대 870). 시작 3회, 빈민가에서 4회. M1 구간에 강화 재료 2개 |
| 진흙 경단 | 12초에 걸쳐 300 회복 |
| 관통(상태이상) | 최대 체력 20% + 150 폭발 피해 |
| 감염 | 180초 동안 초당 공명율 1% 감소 |
| 패리 | 실패 시 공명율 10% 소모(10% 이상 있어야 사용 가능), 성공 시 소모 없음. 잡기·큰 광선·교단 번개는 패리 불가, 투사체는 반사. 입력 후 보호되지 않는 준비 동작이 있어서 맞기 약 0.5초 전에 눌러야 한다 [커뮤니티]. 실제 판정창 길이는 미확인 [추정] |
| 회피 | 소모 없음. 락온 중에는 대시, 아닐 때는 구르기. 무적은 시작부터 중반까지 [커뮤니티] |
| 해금 순서 | 패리 → 방패(둘 다 하수도) → 클로(공포의 수확자) → 대시(후반) |
| 방패 | 5회 막으면 과부하 폭발 |
| M1 주문 | 레일건(공명율 20%, 보스 행동 끊기), 부분 재구성 회복(60%), 화염 분사(25%) |

### 2.3 무기 [확인]
- 내부 동작 세트는 5종이다: 장검, 쌍검, 대검·창 공용, 클로, 태도.
- 무기마다 R2 변형(짧게 누르면 특수, 길게 누르면 차지)과 고정 스킬 하나(공명율 20~40%, 타격마다 지불)가 붙는다.
- M1까지 얻는 무기: 녹슨 장검, 블레이더 무기 중 택1(장검/쌍검/대검), 단조 강철 칼날, 뼈 부수개, 톱날 미늘창, 녹슨 파이프, 곡괭이, 오염된 블레이더 대검(관통 17), 상점의 주철 대검과 충격 드릴. 태도는 후반.

### 2.4 M1 적 [확인/커뮤니티]
- **하수도**: 공허 몹(큰 배수관 안의 개체는 두 번째 타격 뒤 반격하고 뒤잡기를 버틴다), 꼬리 휘두르기가 늦게 오는 공허 짐승, 빨간 눈 번쩍임이 패리 신호인 청소 로봇, 레이저 기계 복도, 감염을 거는 비명 부유체(중간 보스), 벽에 부딪히게 만드는 구르는 달팽이, 쌍검을 쓰는 길 잃은 블레이더. 문 뒤·안개 속·상자 속 연출 매복이 많다.
- **빈민가**: 처치하면 다시 생기지 않는 조준선 저격수, 척탄병, 위에서 떨어지는 약탈자, 전기 모자 교단 경비, 관통을 쌓는 칼날 팔 부식체와 감염 범위기를 쓰는 빠른 변종, 부식체 파리, 가시 알 함정, 족장 앞에서 굴러오는 통. 세력 간 싸움(부식체가 약탈자 캠프 습격), 관통 공격을 쓰는 길 잃은 블레이더 2.

### 2.6 난이도 데이터 [확인: 스팀 업적]
시작 91.7% → 로르 처치 77.0% → 공포의 수확자 처치 67.8% → 최종 보스 43.8%. **전체 이탈의 약 절반이 M1 두 구역 안에서 일어난다.** 처음 하는 사람 기준 보스전 길이는 튜토리얼 보스 40~60초, M1 보스 1~2.5분. 주요 사망 원인은 낙하, 매복, 관통 폭발, 잡기, 빠른·늦은 지연 공격이다 [커뮤니티].

중국 공략에서 실제로 쓸 만한 관찰점도 얻었다: 로르의 손 들기·연속 찌르기·세 번째 도약, 족장의 오른손 잡기 신호, 수확자의 회전 뒤 팔 위치 [커뮤니티]. 다만 패리·회피 무적·보스 선딜의 재현 가능한 프레임 표는 어디에도 없다. "0.3초" 같은 값은 체감 입력 선행 시간이다.

**밸런스 변경 주의** [확인]: 2025년 8월부터 패리 비용을 없애는 각인에 "사용 중 받는 피해 증가" 대가가 붙었고, 기술 전환 공격의 무한 연계가 수정됐다. 출시 초기 영상으로 현재 밸런스를 판단하면 안 된다.

### 2.7 전투 구현 권장 (20틱/초 기준)
1. 공명율은 0~100 하나의 자원, 인장별 단계 구간은 2.2절대로. Epic Fight 스태미나를 대체한다. 회피 0, 패리는 실패할 때만 10.
2. 패리: 보호되지 않는 준비 약 8~10틱, 판정 약 6~8틱 [추정, PC에서 측정 필요]. 성공하면 보스별 경직(M1은 57~88틱, 로르 2페이즈 147틱)을 주고, 처형 입력은 그 안의 구간에서만 연다.
3. 강인도(40~80)와 경직(28~50틱)을 Epic Fight 경직·강인도 수치로 옮긴다. 약공은 거의 경직을 주지 않고, 스킬과 주문은 준다.
4. 틱당 회전 상한: 청소부 6°, 로르 9°, 족장 10°, 수확자 15°. 보스가 플레이어를 얼마나 따라 돌지, 돌아서 피하기가 얼마나 통할지가 여기서 정해진다.
5. 예고 동작은 어디서나 최소 0.5초(10틱). 잡기마다 구분되는 신호를 둔다.
6. 처형 일격은 무기가 아니라 캐릭터 레벨로 오르고 파쇄 피해를 준다. 보스의 파쇄 방어는 낮게.
7. 초반 밸런스 목표: 수액 병 한 번에 최대 체력의 약 54% 회복, 보스 한 방에 체력 25~50%, 관통 폭발은 체력 약 절반.
8. 프레임 단위 타이밍은 PC에서 보스 처치 영상을 프레임 단위로 넘겨 재야 한다.

## 3. 서사, NPC, UI, 아트, 사운드

### 3.1 M1 서사 흐름 (요약, 원문 대사는 쓰지 않음) [확인]
- **하수도**: 내레이션 → 진흙 속 각성 → 시종이 "주인님께 시간이 없다"고 알림 → 안내자와 첫 체크포인트를 함께 수리, 기억 장면, 회복약과 무기 3택 1 "작별 선물", 임무 부여("사람을 만나고 가지를 되살려라") 후 안내자가 녹아 사라짐 → 그녀를 따르던 이들이 보스에게 죽었다는 주민의 원망(세계가 그녀의 죽음에 반응) → 보스 처치 뒤 안내자의 녹음된 목소리가 공허의 정체를 설명 → 성벽 경치와 지도
- **빈민가 캠프**: 식물학자가 주인공의 눈을 보고 다른 사람으로 착각, 흙이 문제라고 설명하며 정화된 흙을 줌 → 아이 순례자가 낙원을 전도하고 인형 이름을 따 주인공에게 이름을 지어 줌, 통행 인장 → 상인이 세계 안의 논리로 교역을 설명 → 교단 목자 문지기
- **빈민가 끝까지**: 족장 등장 장면에서 그가 부하들에게 도망치라고 명령(산적 두목이 사실은 보호자) → 수확자의 코어 "기억"이 기계 명령 로그처럼 읽힘(부식체가 조종당한다는 암시) → 캠프가 반응하고 아이는 떠나며, 식물학자의 호의가 보스 처치 여부에 따라 달라짐 → 입구에서 관을 진 인물이 "그릇" 시체를 거두며 의뢰를 줌
- **따라 할 기법**: 대화를 끝까지 하면 열쇠 아이템, 능력을 주는 기억 잔향, 보스 코어마다 2~4줄의 인용(일부는 웃김), 아이템 설명은 기능·설정·기억 3층.

### 3.2 NPC 퀘스트 구조 [확인/커뮤니티]
- 모든 NPC의 단계표(묶인 체크포인트, 선행 조건, 내용, 보상, 놓칠 수 있는 지점)는 노트에 있다.
- **단계를 넘기는 계기**: 대화 소진, 체크포인트에서 휴식(쉬면 NPC가 자리를 옮김), 보스 처치, 아이템 전달, 다른 NPC의 플래그, 구매 횟수.
- **실패 지점**: 전역 귀환 불가 지점 하나(황금 가지 획득 시 미완료 NPC 제거), 순서 함정(특정 인물에게 너무 일찍 말 걸기), 자비 처치 부탁을 무시하면 보상을 든 변이 부식체가 근처를 배회.
- 노트에 데이터 모델(YAML) 제안이 있다.

### 3.3 HUD와 UI [확인: 게임 화면 / 해석은 커뮤니티]
- **가운데 아래**: 양 끝에 화살표가 달린 얇은 공명율 선, 채움 끝 위에 퍼센트. 단계 색 회색 → 하늘색 → 파랑 → 보라 → 빨강. 그 아래 더 짧은 흰 체력 바, 그 밑에 상태 아이콘.
- **왼쪽 아래**: 회복약 개수, 퀵슬롯 3칸, 정수 총액과 "+획득" 표시.
- **오른쪽 아래**: 진흙이 흘러내리는 테두리의 마름모 틀 안에 왼팔 기능, 대각선으로 놓인 무기 아이콘 2개, 주문 슬롯.
- **보스 바**: 맨 위 가운데 아주 얇은 선, 가시 달린 양 끝, 위에 세리프 이름, 빨간 잔상 피해.
- **획득 알림**: 일반 아이템은 작은 토스트, 열쇠 아이템과 인장은 큰 보라 붓질 배너.
- **대화와 컷신**: 대화창 없이 아래 가운데 세리프 자막, 오른쪽 아래 확인·건너뛰기. 메뉴를 열면 게임이 멈춘다.
- **메뉴**: 3단(능력치 / 목록 / 상세), 숯색 배경, 은색 이중 테두리, 얇은 빨간 선. 능력치는 신체 / 기량 / 방어 / 저항으로 묶음.
- **체크포인트 흐름**: 수리 → 휴식 → 레벨업 / 강화 / 이동 / 육성 / 인장 재작성 / 능력치 재분배 / 회차.
- **사망**: 들고 있던 정수의 (100 − 핵 유지율)%를 잃고, 부활할 때 진흙 끓는 소리.
- **불만(일부 패치됨)**: 메뉴로 주문 전환, 달리기와 회피가 같은 키, 무기를 넣는 동작 없음, 검은 로딩 화면.

### 3.4 아트 방향 [확인: 제작진 인터뷰]
- 셀 셰이딩 캐릭터 + 사실적 배경. 이유: 팀이 *BLAME!*을 좋아하고, 젊은 층에 통하며, 예산이 적었다.
- *BLAME!*의 영향: 복잡한 동선, "어디에나 있는 파이프와 케이블", 쌓인 잔해. 도시는 브루탈리즘 콘크리트.
- **규칙: "식물이 멸종했다."** 배경에 식물 장식이 없다.
- 주인공 정체성: 피부 균열, 진홍 갑각 왼팔, 빛나는 동공. 초기의 긴 분홍 머리가 짧은 연분홍으로 바뀌었고, 옷은 "황무지 누더기".
- 부식체: "가시, 칼날, 촉수, 은빛 껍질, 곤충 날개". 무기는 "고철을 주워 만든" 철학.
- 캐릭터는 그림자를 두 톤으로 딱 끊고 외곽선을 넣는다 [커뮤니티, 화면 관찰].
- **팔레트**: 하수도는 차가운 청흑색 + 청록 체크포인트 + 녹슨 빨강, 빈민가는 바랜 세피아·황토 + 붉은 사암. 16진수 값은 노트에 있다.
- **세력 색**: 교단 흰 도자기·금 장식·로열 블루·짙은 빨강 망토·금 번개, 순례자 크림색 후드 로브, 공허 검은 진흙 + 용암 주황 균열, 부식체 '파쇄' 피해는 보라 발광.
- **비판**: 같은 재질이 반복되는 휑한 회색 복도 [커뮤니티].

### 3.5 음악과 소리 [확인/커뮤니티]
- 작곡: Vanguard Sound(Punishing: Gray Raven 제작 스튜디오), 27곡.
- 구조: **지역마다 배경 루프 하나, 캠프 전용 곡, 세력별 공용 보스곡 4개(인간 / 부식체 / 교단 ×2), 주요 보스 6명의 2페이즈 전용곡.** 1차 조사의 "보스곡 하나 공용"은 틀렸다.
- 평가: 필드 음악은 무난하지만 기억에 안 남고, 보스 음악은 훅이 없다. 패리 금속음과 타격감은 좋다. 저격 전 경고음이 회피를 돕는다. 사망 시 진흙 끓는 소리. 가장 많이 비판받은 것은 주인공의 단조로운 목소리.

### 3.6 설계 권장
1. M1 골격은 노트 8장의 흐름을 쓰되 이름·디자인·글은 전부 새로 만든다.
2. 퀘스트 단계는 모두 체크포인트에 묶고, 쉬면 NPC가 자리를 옮기며, 귀환 불가 플래그는 하나만 둔다. 다른 NPC 플래그에 따라 대사를 바꾼다.
3. 보스 코어마다 2~4줄의 잔향 대사, 아이템마다 기능 줄 + 설정 줄.
4. 퀘스트 표시 대신 주인공의 혼잣말 힌트와 지도의 NPC 이름.
5. HUD는 3.3절 배치를 따른다. 일반 획득은 토스트, 열쇠 아이템은 배너. 튜토리얼 수첩 아이템. (메뉴 일시정지 여부는 UI 문서에서 결정)
6. 캐릭터 텍스처에 두 톤 그림자와 외곽선을 칠한다. 배경 재질은 더 풍부하게, 식물 금지, 장면마다 채도 높은 강조색 하나.
7. 세력 색 코드를 유지한다.
8. 음악: 지역 루프 + 거점 곡 + 세력 공용 보스곡 + 이야기 보스 2페이즈 전용곡. 모두 훅이 있게.
9. 우선 효과음: 패리 금속음, 원거리 공격 전 경고음, 사망 시 진흙 끓는 소리.
10. 아이 캐릭터는 연령에 맞게, 주인공은 확실히 젊은 성인으로 보이게(원작 주인공은 "13살 같다"는 평을 받았다).
